# Original art provenance

GoldenPad's app icon is project-owned original art created for this repository
on 2026-08-03 and refined on 2026-08-04 with OpenAI's built-in
image-generation tool. The refinement used only the prior project-owned icon as
an input image; no external art or style reference was supplied.

The brief requested an abstract gold `G` merged with four-direction geometry,
one sea-glass teal accent, a midnight background, strong small-size silhouette,
and no franchise imagery. It explicitly excluded Bond/007, guns, crosshairs,
tuxedos, Nintendo/Rare marks, N64 controller shapes, GoldenEye branding and
HarkinianPad imagery.

The refinement preserved that identity while requesting a crisper small-size
silhouette, restrained dimensional depth, balanced full-bleed spacing, and no
baked rounded-corner mask. The selected opaque RGB source was 1254×1254. It was
resized to the tracked 1024×1024 `AppIcon-1024.png` with macOS `sips`; no
external artwork was added.
The tracked source SHA-256 is
`909783109a6b47bbd49159f0d5a769bf62094cdc067e67f240193adaa05fc15d`.
Xcode compiles phone and tablet renditions from that single source. Launcher
appearance for the refined source was visually verified sequentially on iPhone
16 Pro and iPad Pro 11-inch (M4) simulators; each clean app container was removed
before the next device pass.

No generated game art, screenshots or copyrighted game assets are tracked.
