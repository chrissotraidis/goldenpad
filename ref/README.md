# Local references

This directory is for private, local development inputs and inspected upstream
checkouts. Its contents are ignored by Git except for this notice.

Never commit, push, package, publish, document, or capture in screenshots:

- retail ROM images;
- extracted or generated game assets;
- leaked source code or unreleased builds;
- credentials, signing keys, or provisioning profiles.

The authoritative inventory of reviewed upstream projects, including exact
commits, licenses, provenance, and intended use, lives in `docs/RESEARCH.md`.
